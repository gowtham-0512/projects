# Student Result Management System

A console-based Java application to manage student academic records.

## Features
- Add Student
- Display All Students
- Sort by Marks
- Show Class Topper
- Search Student
- Grade Calculation

## Technologies Used
- Java
- OOP Principles
- ArrayList
- Comparator
- Collections Framework

## How to Run

1. Compile:
   javac *.java

2. Run:
   java Main

## Concepts Demonstrated
- Object-Oriented Programming
- Sorting using Comparator
- Searching
- Data management using Collections
